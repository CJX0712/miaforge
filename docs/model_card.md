# MiaForge 模型卡（Model Card）

作者：晨星

## 模型详情
- **系统**：MiaForge —— 成员推理攻击（Membership Inference Attack, MIA）评测系统
- **被攻击目标**：纯 numpy MLP（1 隐层 32 单元，Adam + softmax 交叉熵），训练于 `sklearn.load_digits`（8×8 手写数字，1797 样本 / 64 特征 / 10 类）
- **攻击者**：Shokri 影子模型攻击（`shadow_all`）—— K=10 影子模型积累监督 + 纯 numpy 逻辑回归融合完整概率向量与辅助线索
- **基线**：Yeom 2018「blind」loss 阈值攻击（`loss_threshold`）

## 预期用途
- 演示并量化「训练样本是否可被推断」这一隐私攻击面
- 作为 MIA 方法对比的标准化评测台（基线 / 旗舰 / 消融 / 失败案例）
- 教学与研究：可复现、零重型依赖、确定性

## 训练数据
- 来源：`sklearn.load_digits`（本地内置，无需联网）
- 规模：成员 200 / 非成员 200；影子池 1397（与成员/非成员互不相交）
- 预处理：逐特征标准化（μ/σ）
- 类别平衡：原始 digits 分布

## 评测结果（默认配置，3 seed 聚合）

| 方法 | AUC | 备注 |
|------|-----|------|
| loss_threshold（基线） | 0.592 | 单 loss 阈值，ROC 上限 |
| **shadow_all（旗舰）** | **0.651** | 完整概率向量 + 多线索 |
| shadow_loss_only | 0.592 | 消融①：仅 loss → 退回基线 |
| shadow_no_correct | 0.653 | 消融②：去 correct（几乎无损） |

- 门禁 delta = +0.059（≥0.02）✓；显著（delta > ½(σ₁+σ₂)）✓ → **PASS**
- 确定性：二次运行逐位一致 ✓

## 局限性
- 数据集为低分辨率数字，难度远低于真实视觉/语言大模型场景；AUC 仅作方法验证。
- 轻量可复现版，未实现 LiRA（Carlini 2022）的高阶逐类高斯似然比；评测时如实对标。
- 在小样本、较强容量设定下运行；结论不直接外推到生产级模型。

## 伦理与滥用
MIA 是**防御性隐私评测**工具：帮助研究者量化模型记忆与训练数据泄漏风险。禁止用于未经授权推断真实个体是否出现在他人模型中。
